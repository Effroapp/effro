Before. The dashboard as it is today, for comparison. The nudge takes the first slot, the area grid has no label, and Coming Up sits collapsed at the bottom with a red count.

Stacked. Same content, fixed order, full width. A status line replaces the nudge under the greeting. Every zone gets the same header with a count and one action. In Hand is the heaviest text on the page. Coming Up opens by default and overdue is one quiet line. The area filter moves into the Areas header.

Split. In Hand stays full width as the anchor. Coming Up and Areas share a 60/40 band beneath it on wide screens. Switch to Narrow to see it stack like Stacked. This is the default.

Rail. Two columns on wide screens. In Hand and Coming Up in the main column, Areas as a compact list in a right rail so the map is always in view. Switch to Narrow to see it stack like Stacked.

Plain. A floating heading in the display face. Nothing contains it, so the association is by proximity only.

Lifted. The heading stays outside. The body loses its border and sits on a soft shadow, with the gap closed to 6px so the shadow does the associating.

Sheet. Heading inside a lifted sheet with a hairline under it. No tinted bar, no border.

Inset. Heading on a lifted sheet, with the rows set into an inner panel. The header is the sheet's own margin. This is the default.

Folder. The heading is a folder tab on the sheet, one silhouette and one shadow. Reads as a labelled folder, though a lone tab can hint at other tabs that aren't there.

Margin. A notebook margin line runs down the left of heading and body. Flat, no shadow. The shared line is the association.

Boxed. A tinted title bar inside a bordered box, the way the current In Hand strip does it.
